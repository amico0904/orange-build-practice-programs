# 독립 검증 결과

## 기존 검증 담당의 재검증

같은 팀의 wb_reviewer가 기존 작업을 이어가 원본 정상 CSV 3개와 errors.csv를 각각 계산했다. 요청한 GPT-6.1 Sol / Medium 실행 기록을 확인했다. 대시보드 코드나 원본 자료는 변경하지 않았다. 아래 기대값은 원본 자료를 직접 계산한 값이며, 실제값은 Node에서 실행한 데이터 코드와 DOM 모의 실행의 출력이다. 최종 재실행은 exit code 0으로 통과했다.

| 자료 | 기대 행수 | 실제 행수 | 기대 참여/수료 | 실제 참여/수료 | 기대 수료율 | 실제 수료율 표시 |
|---|---:|---:|---:|---:|---:|---:|
| 정상 전체 | 18 | 18 | 1,410 / 1,171 | 1,410 / 1,171 | 83.0496% → 83% | 83% |

정상 전체에서 연도 3개, 사업 6개, 기본 주의 1행도 일치했다. 수료율은 합산 수료자 ÷ 합산 참여자로 계산하며 판정은 표시 반올림 전 값에 적용한다.

### 필터·CSV·오류 사례

- 전체 및 각 연도 필터에서 요약·파이·막대·추이·표·CSV를 동일 행과 대조했다. aggregate와 export에 같은 행 객체가 전달되는 것도 확인했다.
- 다운로드 이벤트가 생성한 실제 Blob을 검사했다. UTF-8 BOM(EF BB BF), 원본 한글 7개 열과 순서, 전체 18행 또는 선택 연도 6행, 재입력 왕복이 모두 일치했다.
- errors.csv는 별도로 검증했다. X01의 첫 유효 행과 X03의 0명 행을 유지하고, 0명 행의 수료율·판정은 계산 불가로 표시했다.
- 오류 행의 실제 사유 표시: 원본 3행 중복, 4행 참여자수 누락, 6행 수료자 초과. 유효 2행·제외 3행이 일치했다.
- 음수·소수·수료자 누락 및 앞의 무효 행 뒤에 유효 중복 행이 오는 사례도 확인했다.
- 신규 2029년 자료 두 사업(참여/수료 7/3, 13/11) 업로드는 합계 20/14·70%, 파이 35%/65%, 해당 막대와 CSV 2행으로 변경됐다. 정답 수치로 화면을 고정하지 않았음을 확인했다.

기대 결과와 다른 항목은 발견되지 않았다. 수정할 코드가 없어 기존 대시보드를 유지했다. 브라우저 자동 확인은 현재 URL을 확인하지 못해 차단됐으므로 실제 렌더링과 브라우저 다운로드 조작은 미확인이다. DOM 모의 실행을 실제 브라우저 확인으로 표현하지 않는다.

## 최초 제작 검증 기록
