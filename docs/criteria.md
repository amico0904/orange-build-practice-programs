# 통합 대시보드 계산·검증 기준

## 데이터 규칙

- 입력 CSV의 필수 열은 `연도,사업ID,사업명,분야,지역,참여자수,수료자수`이며, 출력도 이 한글 열 이름과 순서를 그대로 사용한다.
- 중복 키는 `(연도, 사업ID)`다. 숫자와 필수 값 검증을 통과한 행 중 먼저 나온 행만 유효하다. 앞선 행이 유효하지 않으면 뒤의 유효 행이 남을 수 있다.
- 참여자수와 수료자수는 빈 값이 아닌 0 이상의 정수여야 한다. 수료자수가 참여자수보다 크면 제외한다. 제외 사유는 `연도 누락`, `사업ID 누락`, `참여자수 누락/정수 아님/음수`, `수료자수 누락/정수 아님/음수`, `수료자 초과`, `중복`처럼 구체적으로 표시한다. 한 행에 여러 오류가 있으면 사유 배열에 모두 기록한다. 중복 검사는 그 외 유효성 검사를 통과한 행에만 적용한다.
- 0명·0명 행은 유효 자료에 남긴다. 개별 수료율과 판정은 `계산 불가`이며 차트의 수료율 계산에는 기여하지 않는다.
- 행별 수료율은 `수료자수 ÷ 참여자수 × 100`, 전체 및 연도별 수료율은 `해당 행 수료자 합계 ÷ 해당 행 참여자 합계 × 100`이다. 사업별 비율의 단순 평균은 금지한다. 분모 합계가 0이면 계산 불가다.
- 수료율이 기준(threshold) 미만이면 `주의`, 기준과 같거나 크면 `정상`이다. 기본 기준은 70%이며 기준은 UI에서 바꿀 수 있다. 표시 퍼센트는 정수 백분율로 반올림하고, 집계는 반올림 전 값으로 한다.
- 기본 대시보드는 정상 파일 2024.csv, 2025.csv, 2026.csv만 사용한다. errors.csv는 기본 샘플에 섞지 않고 오류 확인용으로 별도 제공한다.

## `window.ProgramData` 계약

화면 구현은 아래 API와 반환 필드를 사용한다. `aggregate`만 임계값 변경과 상세 표를 동기화하기 위해 전달된 유효 행의 `rate`, `status`를 갱신한다. 비율은 0–100 범위 숫자 또는 `null`로 반환한다.

```js
window.ProgramData = {
  SAMPLE_FILES: [{ name: "2024.csv", text: "..." }, /* 2025, 2026 */],
  ERROR_SAMPLE_FILES: [{ name: "errors.csv", text: "..." }],
  parseFiles(files),
  filterRows(rows, years),
  aggregate(rows, threshold = 70),
  exportCSV(rows)
};
```

- `SAMPLE_FILES`에는 기본 정상 샘플 3개만, `ERROR_SAMPLE_FILES`에는 오류 예제만 둔다. 둘은 합쳐서 기본 데이터로 로드하지 않는다.
- `parseFiles([{name, text}, ...])`는 CSV를 파싱하고 행 검증까지 해 `{rows, excluded}`를 반환한다. 유효 `rows`는 원본 한글 열과 `source`(파일명), `line`(원본 1 기반 행 번호)를 가지며, 수치는 정수로 정규화한다. 행별 `rate`(수료율)와 `status`(주의/정상/계산 불가)는 현재 기본 기준 70으로 계산한다. 제외 항목도 원본 열 및 출처를 보존하고 `reason`을 담는다. 입력 파일 및 행 순서를 유지하고 빈 줄은 무시한다. 필수 헤더가 없는 파일은 그 파일의 자료행을 제외하고 파일 단위 사유를 기록한다.
- `filterRows(rows, years)`는 지정한 연도 배열의 행만 반환한다. 비었거나 빠진 연도 배열은 전체를 뜻한다. 반환 행의 순서는 입력과 같다. 필터 대상은 연도이며, 화면의 모든 지표·차트·표·내보내기가 이 동일한 행을 사용한다.
- `aggregate(rows, threshold = 70)`는 `{summary, fields, programs, trend}`를 반환한다. `summary`는 `{count, participants, completers, rate}`, `fields`는 `{name, participants, share}` 배열, `programs`는 `{id, name, participants, completers}` 배열, `trend`는 `{year, participants, completers, rate}` 배열이다. 이 네 묶음은 모두 전달받은 같은 행에서 계산한다. `rate`는 합계 기준이며 사업별 비율의 단순 평균을 사용하지 않는다. 함수는 행별 `rate`와 `status`를 현재 threshold로 다시 계산해 전달받은 rows에 기록한다. 따라서 상세 표도 aggregate 호출 뒤 해당 rows를 그대로 렌더링하여 판정을 동기화한다. `rate < threshold`만 `주의`, 그 외 계산 가능한 행은 `정상`이다. 0명 행의 rate/status는 `null`/`계산 불가`다.
- `exportCSV(rows)`는 전달된 행 순서대로 한글 헤더와 원본 7개 열만 직렬화한 CSV 문자열을 반환한다. 필터 내보내기는 호출 전에 `filterRows`를 적용한다. 쉼표·큰따옴표·줄바꿈이 있는 셀은 CSV 인용 규칙을 따르고 큰따옴표를 두 번 쓴다. 출처·계산 필드는 출력 열에 추가하지 않는다.

제공 정상 CSV와 errors.csv를 함께 선택하면 혼합 로드를 거부하고 기존 자료를 유지한다. 정상 자료와 오류 자료는 별도로 선택해 확인한다. 제외 행과 파일 오류는 별도 오류 목록으로 확인한다. 모든 요약, 분야 파이, 사업별 참여·수료 막대, 연도별 수료율 추이, 상세 표, CSV는 동일한 연도 필터 결과를 사용한다. 기준 색상과 범례 항목은 필터 후에도 고정한다.

## 검증 기대값

| 입력 | 유효/제외 | 참여 합계 | 수료 합계 | 합계 기준 수료율 |
|---|---:|---:|---:|---:|
| 2024–2026 정상 샘플 | 18 / 0 | 1,410 | 1,171 | 83% (정확히 약 83.05%) |
| errors.csv 별도 선택 | 2 / 3 | 20 | 15 | 75% |

정상 샘플은 3개 연도 및 6개 사업의 18개 행을 보여야 한다. errors.csv에서는 중복의 첫 행과 0명 행이 유효하고, 0명 행은 계산 불가다. 오류 파일의 다른 3행은 각각 중복, 숫자 누락, 수료자 초과로 제외한다. 기준을 80%로 바꾼 점검에서는 75%가 주의, 정확히 80%는 주의가 아니며 정상 샘플의 합계와 83% 표시는 변하지 않아야 한다.

연도별 정상 샘플 합계는 2024년 참여 400명·수료 320명(80%), 2025년 470명·388명(약 82.55%), 2026년 540명·463명(약 85.74%)이다.

## 제외 이유 및 해석

오류 행은 합계·차트·상세 유효 표·CSV에서 제외하고, 별도 목록에서 원본 행과 제외 사유를 보인다. 파일 헤더 오류는 행 오류와 구분해 파일 단위로 보고한다. 0명 행은 오류가 아니므로 유효 상세 표와 CSV에 포함하지만 분모 0인 비율 지표에서는 계산 불가로 표시한다.
