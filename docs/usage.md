# 여러 사업 실적 통합 대시보드 사용법

## 실행

프로젝트 폴더의 `index.html`을 Chrome 또는 Edge로 여세요. 별도 서버나 설치가 필요하지 않습니다. `index.html`, `styles.css`, `data.js`, `app.js`를 같은 폴더에 유지하세요.

## 자료 확인 순서

1. 처음 열면 코드에 포함된 2024·2025·2026 정상 샘플이 표시됩니다. 18행, 참여자 1,410명, 수료자 1,171명, 수료율 83%, 사업 6개, 연도 3개를 확인하세요.
2. 연도 필터를 바꾸고 요약·파이·막대·추이·상세 표가 함께 바뀌는지 확인하세요. 2024년은 참여자 400명, 수료자 320명, 수료율 80%입니다.
3. CSV 파일 선택에서 `data/programs/2024.csv`, `2025.csv`, `2026.csv`를 함께 선택하면 선택한 파일로 자료를 교체합니다.
4. 선택 연도의 CSV를 다운로드하고, 내려받은 CSV를 다시 선택해 같은 자료를 읽을 수 있습니다. 출력 열은 원본과 동일한 `연도,사업ID,사업명,분야,지역,참여자수,수료자수`입니다.
5. 오류 예제를 선택하거나 `errors.csv`만 따로 선택하세요. 유효 2행, 제외 3행, 참여자 20명, 수료자 15명, 수료율 75%가 표시되어야 합니다. 제외 이유와 0명 행의 계산 불가 표시를 확인하세요.
6. 주의 기준을 80%로 바꾸면 75%는 주의, 정확히 80%는 정상입니다. 정상 샘플로 복원하면 원래 자료를 다시 볼 수 있습니다.

수료율은 선택 자료의 수료자 합계를 참여자 합계로 나눠 계산합니다. 0명·0명 행은 표와 CSV에 남지만 개별 수료율과 판정은 계산 불가입니다. 정상 파일과 오류 예제는 별도로 확인하세요.

## 다음 실행

브라우저를 닫은 뒤에도 같은 `index.html`을 다시 열면 기본 정상 샘플에서 시작합니다. 새 자료는 파일 선택으로 다시 불러오세요.
